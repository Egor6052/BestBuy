## Compiling in the directory ./build
---
Configuration:
```sh
cmake ..
```
Compile the binary:
```sh
cmake --build .
```
Start:
```sh
sudo ./start
```


## Libraries and extensions
---
**For JSON format:**
**Debian** apt
```sh
sudo apt install nlohmann-json-devel
```
**Fedora** dnf
```sh
sudo dnf install nlohmann-json-devel
```
